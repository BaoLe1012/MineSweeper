# MineSweeper

A classic Minesweeper game built using standard **HTML**, **CSS**, and **JavaScript**.

---

## 📌 Project Overview
This project is developed as a team assignment for learning JavaScript fundamentals, DOM manipulation, and modular code organization.

* **Tech Stack:** HTML, CSS, JavaScript

---

##  Project Structure

```text
minesweeper/
├── index.html          # Main HTML entry point
├── README.md           
└── src/
    ├── css/
    │   └── style.css   # Board styles & layout
    └── js/
        ├── board.js    # Board matrix & mine placement logic
        ├── ui.js       # DOM rendering & click event handling
        └── main.js     # Game state management & algorithms
